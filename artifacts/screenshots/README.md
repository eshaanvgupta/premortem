# Screenshot provenance

`home-desktop.png`, `home-mobile.png` and `lab-desktop.png` are actual browser captures of the locally served production application. The registry is unconfigured, and the UI correctly shows the predeployment state.

`war-room-local-test.png` and `proof-local-test.png` were captured during the isolated Anvil browser workflow. Their addresses, identities, transactions and participant counts are synthetic **test-only fixtures**, not genuine mainnet users or adoption evidence. They must never be presented as a deployed mainnet workflow.

No public website deployment or real Agentic Wallet signing is established by these images.
