# 90-second demo script

Use the real application and actual verified deployment only after operator approval. If showing the local undeployed build, state that clearly and retain the deployment-unconfigured state. Never edit the screen to imply broadcasts or adoption.

| Time   | Screen and narration                                                                                                                                                                                                                                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–12s  | Home: “An agent can submit an action before it understands every failure path. PREMORTEM lets the future fail before it happens: evidence first, advisory decisions second.” Show genuine chain/config state.                                                                                                     |
| 12–30s | Preflight Lab: inspect a real proposal with exact sender/target/value/calldata. “These branches come from code lookup, selector decoding and exact RPC call/gas observations. Unknown stays unknown. A successful call is not a security guarantee.” Open one node and raw JSON.                                  |
| 30–43s | Prepare capsule: show exact action/evidence hashes, mode, quorum, deadlines and public-data consent. “The protocol stores hashes and a bounded label; the original asset action is never executed.”                                                                                                               |
| 43–57s | Trusted local terminal: show real `baw` settings and preview through the wrapper. Read destination, method, value zero plus gas and risks. The human confirms; an actual App pending state remains pending. Use an already confirmed real receipt if recording time is short; identify it honestly.               |
| 57–72s | War Room: demonstrate another holder's substantive review or a real blind room's previously committed/revealed events. “Each account gets one independent review. A secret salt binds the vote to this room and this wallet; missing reveals do not count.” Never accelerate mainnet time or fabricate reviewers. |
| 72–84s | Flight Recorder: export/verify the actual receipt and open its BscScan transaction. “The outcome is advisory; you are free to act elsewhere, and PREMORTEM never holds funds.”                                                                                                                                    |
| 84–90s | Live Proof: show the exact complete/partial coverage status and actual distinct-address metric. “No fake users, no fictional safety score: proof before action.”                                                                                                                                                  |

Capture captions, keyboard-focus states and mobile view when possible. Any recording cuts should preserve the sequence's truth. A script is provided; no recorded video is claimed.
