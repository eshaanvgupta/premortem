## Reproducible production build

`pnpm build:production` loads `packages/contracts/deployments/mainnet.json` and `site.json`, then embeds only public configuration. `pnpm verify:mainnet` independently refreshes receipt/runtime checks without signing. `pnpm prepare:mainnet` now rechecks an existing deployment rather than overwriting it with an undeployed status. See [launch handoff](MAINNET_LAUNCH.md) for wallet and packaging details.

The Sites static host did not apply `_headers` as HTTP response headers. The application includes a document CSP, and the Next.js server deployment retains the authored HTTP security headers. Hosts requiring HTTP header enforcement must configure those headers at the edge. Existing local Docker and Lighthouse results are historical executed evidence; they are not a separate security audit of the live host.
