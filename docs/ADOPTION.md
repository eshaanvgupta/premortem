# Genuine review missions and adoption

The Innovation Award requires at least 30 genuinely distinct Agent ID addresses to interact during the official submission period. Recruitment is external work: the repository cannot create users, claim IDs, guarantee uniqueness of humans or manufacture organizer approval. Do not run bot farms, random wallet generators, duplicate activity scripts, fake volume or empty review transactions.

Invite ecosystem members who actually want adversarial review. Each participant should read evidence and contribute an original capsule, meaningful category/observation/confidence review, or rival evidence. One thoughtfully documented review is preferable to repeated activity. Public on-chain participation discloses the sender and contribution; obtain consent, especially before attaching third-party identifying details.

Educational mission ideas, **not on-chain capsules until a real user creates them**:

| Mission                 | Substantive task                                                                                                                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unlimited allowance     | Inspect a real ERC-20 approval. Identify the actual token and spender, distinguish selector decoding from verified implementation, and explain the authority granted. No approval is executed. |
| Unknown contract call   | Inspect an actual unfamiliar selector; document missing ABI/provenance and what evidence would change the verdict. Unknown is an acceptable conclusion.                                        |
| Time-sensitive proposal | Review a real expiring governance/multisig proposal's exact bytes and assumptions. Label any unverified external context and do not impersonate its signers.                                   |

Copyable invitation (replace only with actual published URLs):

> We are testing PREMORTEM, an independent Agent ID-gated advisory review tool. If you already have Agent ID and want to review a real proposed action, you can inspect its evidence and contribute a specific observation with honest confidence. Protocol calls transfer zero BNB to PREMORTEM, but you pay the BSC network gas shown in your wallet preview. Agentic Wallet custom calls require Developer Mode in the Binance App; review its warnings, limit and expiry. All signing stays in your trusted local environment using the official wallet skill and your own explicit confirmation. Public reviews disclose your address and contribution. There is no token, profit promise, reward guarantee or need to execute the underlying asset action. Please contribute only if the review is useful to you.

Estimate gas from the exact current call and quote the result at invitation time; never invent a permanent BNB fee. Offer read-only access to nonholders and official App onboarding links. Do not collect pairing codes, credentials, personal identity information or contacts for mass outreach.

The public inspector should count only canonical confirmed holder-gated protocol events in `[2026-11-18T08:00:00Z, 2026-12-09T08:00:00Z)`, deduplicated by lowercase wallet address. Permissionless finalization alone does not qualify. Check each action's actual block timestamp, known protocol address, successful receipt and event type. Do not include historic activity, testnet, test identities, off-chain sign-ins or pending transactions. Partial scan coverage yields a lower-bound observed count, not a campaign total; show the limitation and range. Organizer recognition is independent of this local metric.
