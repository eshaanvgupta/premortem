# Three-minute product pitch draft

Every consequential agent action starts with a gap: the agent has a plan, but the consequences depend on code, state, permissions and assumptions it may not have examined. A simulator can tell us something about one call at one block. A confident explanation can still be wrong. We need a place to preserve the evidence and ask independent reviewers what could fail before anyone acts.

NEXORA is that preflight room. Our promise is proof before action. Enter the exact sender, target, value and calldata. A deterministic engine retrieves real chain observations, decodes recognized formats, attempts a call and gas estimate, and separates observed facts, heuristics, failures and unknowns. The Future Tree makes these branches inspectable. There is no invented percentage of safety, and no AI model is required.

A user who actually holds the competition's Agent ID can anchor a capsule: exact normalized hashes, a bounded public label, deadlines and review rules. Independent holders add counterevidence and one meaningful review each. They choose a category, reference an observation and disclose confidence. Insufficient evidence is a valid answer. Blind rooms require reviewers to commit before they can see revealed votes; the commitment binds the room, chain, contract, reviewer and full verdict to a private salt. Missing reveals never count.

After the deadline anyone can finalize. The contract records Approved, Rejected or Inconclusive according to fixed quorum and absolute-majority rules. The outcome is advisory. It cannot execute the proposed action, grant approvals, hold funds or block someone who acts elsewhere. A receipt exposes the action hash, events, totals, outcome and chain provenance for independent checking.

Agent ID is not a decorative badge here: the actual sender must pass the official registry's balance check for each substantive contribution. We also do not confuse it with unique personhood or substitute ERC-8004. Real Agentic Wallet calls stay in the user's trusted local runtime. The website prepares a scoped file; official local tooling previews it, displays risks and requires explicit human confirmation. There is no third-party login QR, pairing-code collection or server wallet session.

The product is designed for useful independent review, not transaction farming. Live Proof shows observed eligible addresses only from actual confirmed events and reveals partial coverage. The repository includes the deterministic SDK, immutable registry, local adapter, test suites and deployment runbook. Until real deployment, verification, hosting and consenting-holder signing occur, those remain clearly marked launch requirements. We will report real evidence, never pretend an award threshold has already been met.

NEXORA gives agent ecosystems a shared memory of what was proposed, what was known, what was challenged and how a decision was reached. Let the future fail before it happens.

## Concise explainer thread draft

1. Before an agent takes a consequential on-chain action, ask what could fail. NEXORA combines deterministic preflight with independent Agent ID-holder review. Proof before action.
2. Exact sender, target, value and calldata go into a reproducible manifest. Code lookup, selector decoding and RPC results are facts about a recorded context; heuristics and unknowns stay visibly separate.
3. The Future Tree links each branch to evidence. No fictional prediction percentages. A successful simulation is not a security guarantee.
4. Holders anchor capsules and contribute categorized evidence/reviews. Blind rooms enforce commit then reveal; each independent address completes at most one review. Insufficient evidence is legitimate.
5. Final decisions and their receipts are advisory. NEXORA holds no funds, executes no proposed asset action and grants no approvals.
6. Agentic Wallet signing stays in the user's trusted local environment through official preview and explicit confirmation. No hosted QR login, pairing codes or server wallet sessions.
7. Launch status, verified contracts and genuine participation will be published only when measured. No fake volume, manufactured users or guaranteed rewards. Read the actual code, evidence and limitations before contributing.
